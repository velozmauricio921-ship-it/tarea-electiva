Ejemplo de tarjeta

Aprendiendo
CSS

La tarjeta cambia de tamaño y se acomoda según el ancho de la pantalla.

Usando animation
01

@keyframes latido
scale(1.07) a mitad

02

@media 768 px
columna → fila

animation: latido 1.2s infinite
CSS 04
@keyframes latido {
  50% { transform: scale(1.07); }
}

.study-card { animation: latido 1.2s ease-in-out infinite; }
@media (min-width: 768px) {
  .study-card { display: flex; }
}
